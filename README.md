Dashboard absensi karyawan sederhana yang dikembangkan menggunakan HTML, CSS, dan JavaScript. Proyek ini dirancang untuk mensimulasikan proses administrasi kehadiran karyawan, mulai dari pencatatan absensi, pengajuan izin, pengelolaan lembur, hingga perhitungan penggajian. Melalui proyek ini, saya mempelajari bagaimana mengubah kebutuhan operasional menjadi fitur yang terstruktur serta menyajikannya dalam antarmuka yang mudah digunakan.

Fitur:
- Absensi masuk dan pulang
- Pengajuan izin karyawan
- Pencatatan data lembur
- Simulasi perhitungan gaji
- Dashboard ringkasan data karyawan
- Antarmuka yang sederhana dan mudah digunakan

Tech Stack:
- HTML
- CSS
- JavaScript

Tujuan Proyek:
Membangun simulasi sistem administrasi karyawan untuk memahami alur pengelolaan kehadiran, lembur, dan penggajian dalam sebuah aplikasi web.
